# CS-330 Computational Graphics and Visualization

## How do I approach designing software?

This project helped me improve my ability to plan a scene before writing all of the code. I learned how to break a larger visual idea into smaller objects and then build those objects from simple shapes. I also learned how important placement, scale, lighting, and textures are when trying to make a scene look believable.

My design process was very iterative. I created one object at a time, tested it, adjusted its position or scale, and then moved on to the next part of the scene. I also used multiple camera angles to check whether objects were actually positioned correctly in 3D space. I can use this same approach in future projects by breaking large tasks into smaller pieces and testing each part before adding more complexity.

## How do I approach developing programs?

One strategy I used throughout the project was making small code changes and testing them immediately. This made it easier to identify errors and understand which change caused a problem. I also reused functions for transformations, textures, materials, lighting, and camera behavior instead of placing everything into one large block of code.

Iteration was an important part of the project. Many parts of the scene, including the clock, pencil cup, lighting, and camera controls, were adjusted several times before reaching the final result. Over the course of the milestones, my approach became more organized because I learned to test individual features before combining them into the complete scene.

## How can computer science help me in reaching my goals?

Computational graphics gave me experience working with C++, 3D coordinates, transformations, textures, lighting, collision concepts, and interactive camera controls. These skills can support future coursework that involves graphics, game development, simulation, or other interactive applications.

Professionally, this project also strengthened my debugging and problem-solving skills. Learning how visual systems are built from code gave me a better understanding of how software can control objects, movement, and appearance in a virtual environment. These skills could be useful in future software development or game development work.
